# Hey, I’m Bibas 👋

I’m a Flutter developer from Kathmandu, Nepal. I like building apps that solve everyday problems, and I’m currently working on **[Pocket](https://github.com/bibasshrestha980-npl/expense_tracker)**, a personal finance app for tracking money in Nepal.

Pocket supports Nepali and Gregorian dates, English and Nepali, and can fill in transaction details from bank and wallet SMS alerts. I built it with Flutter, Dart, and Firebase.
