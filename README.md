## 🌟 Flagship Project

### 🌿 [Pocket — Personal Finance & Expense Tracker](https://github.com/bibasshrestha980-npl/expense_tracker)

> A modern, responsive, and full-featured personal expense and income tracker built with Flutter, Firebase, and Clean Architecture. Built for everyday life in Nepal and beyond.

* **🇳🇵 Dual Calendar System:** Seamlessly toggle between **Bikram Sambat (वि.सं.)** and **Gregorian (AD)** calendars with localized month navigation, fiscal periods, and custom date pickers.
* **⚡ Smart SMS & Digital Wallet Parser:** Automatically parses transaction SMS messages from major Nepali commercial banks (Nabil, NIC Asia, Global IME, etc.) and digital wallets (**eSewa**, **Khalti**, **Fonepay**) with instant zero-effort auto-fill.
* **🌐 Full Bilingual Support:** Native English and **नेपाली (Nepali)** localization across all views, reports, and transaction details.
* **🔒 Privacy & Isolation First:** Granular owner-isolated Firebase Firestore security rules ensuring user records remain completely private and secure.
* **🌓 Material Design 3 Theming:** Fluid adaptive interface supporting high-contrast Light, Dark, and System modes with persistent local cache.
* **📊 Analytics & Visual Cash Flow:** Real-time net balance tracking, spending distribution charts, category breakdowns, and exportable statements.
* **🧪 96+ Automated Tests:** Comprehensive unit and widget test suite verifying business logic, parsers, converters, and state management.

👉 **[Explore Pocket Repository & Source Code →](https://github.com/bibasshrestha980-npl/expense_tracker)**
