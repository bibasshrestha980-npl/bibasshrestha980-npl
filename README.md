## 🌟 Flagship Project

### 🌿 [Pocket — Personal Finance & Expense Tracker](https://github.com/bibasshrestha980-npl/expense_tracker)

> A modern, full-featured personal finance application engineered for real everyday life in Nepal. Available on Android, iOS, Web, and Desktop.

* **🇳🇵 Dual Calendar Integration:** Seamlessly switches between **Bikram Sambat (वि.सं.)** and **Gregorian (AD)** calendars with localized month navigation and period summaries.
* **🤖 Smart SMS & Digital Wallet Parser:** Automatically parses transaction SMS alerts from commercial banks (Nabil, NIC Asia, Global IME, etc.) and digital wallets (**eSewa**, **Khalti**, **Fonepay**), extracting amounts, titles, dates, and categories with zero manual typing.
* **🔒 Owner-Isolated Security Architecture:** Granular client and Firestore security rules ensuring user records can never be read or mutated by unauthorized parties.
* **🌓 Material Design 3 Theming:** Fluid adaptive interface supporting high-contrast Light, Dark, and System theme modes with persistent local cache.
* **🌐 Bilingual Experience:** Complete, native localized interface in both **English** and **नेपाली (Nepali)**.
* **📊 Analytics & Visual Cash Flow:** Real-time net balance tracking, daily spending distribution bar charts, category breakdowns, and exportable statements.

👉 **[Explore the Repository & Source Code →](https://github.com/bibasshrestha980-npl/expense_tracker)**
